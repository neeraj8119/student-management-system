# Student Management System

Internship project using React + Vite, Node.js + Express, MySQL, Axios and JWT.

## Run
1. Create MySQL database using `backend/database.sql`.
2. Backend:
   cd backend
   npm install
   npm run dev
3. Frontend:
   cd frontend
   npm install
   npm run dev

Backend: http://localhost:5000
Frontend: http://localhost:5173
